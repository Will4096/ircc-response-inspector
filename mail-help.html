邮箱连接帮助

邮箱辅助为可选功能。连接成功前，继续手动输入验证码即可。只有你确认后，扩展才会提交候选验证码。

163：先安装，再连接

  1. 本机程序仅支持 Windows。首次使用需安装一次，扩展不能自行运行安装程序。
  2. 获取与当前开发版本配套的源码，解压后进入包含 windows 文件夹的目录。可从 开发分支获取；不要使用不明来源安装包。
  3. 在该目录打开 PowerShell，运行下列命令，把 YOUR_EXTENSION_ID 替换为设置页“安装帮助”中的扩展 ID。不是邮箱地址。
powershell.exe -NoProfile -File .\windows\install.ps1 -ExtensionId YOUR_EXTENSION_ID -InstallPython

安装到当前 Windows 用户目录，无需管理员权限。缺少 Python 时，脚本通过 winget 安装；安装失败时保留手动验证码流程，不修改系统执行策略。

  1. 回到扩展设置，点击“检查本机程序”。显示“本机程序可用”后继续。
  2. 在 163 网页邮箱设置中开启 IMAP，生成客户端授权码。
  3. 填写接收验证码的 163 邮箱及客户端授权码，点击“验证连接并启用”。授权码不是网页登录密码。只有已保存同一邮箱连接时，才可以留空。

“本机程序可用”只表示扩展能连接辅助程序，不表示邮箱已经连接。最终以“已连接”为准。

Gmail：开发预览

目前需要自行配置启用 Gmail API 的 Google Cloud OAuth Web 客户端。将设置页显示的 Redirect URI 加入允许的重定向地址，再填写 Client ID 并授权同一邮箱。

Gmail 只读权限可访问邮箱邮件，并非仅限 IRCC 邮件；扩展只在等待验证码时筛选匹配邮件。令牌仅留在内存中，重启或授权失效后需要重新连接。

连接失败怎么办

  • 本机程序未连接：确认已为当前扩展 ID 安装，再重新检查。更换扩展 ID 后需要重新安装绑定。
  • 邮箱验证失败：检查 IMAP 和客户端授权码，不能填写网页登录密码。
  • 无需辅助时，关闭开关即可；手动输入验证码始终可用。

移除连接

设置中“移除本地连接”清除本机邮箱凭据。若不再使用，也请在邮箱服务中撤销授权。卸载本机程序可在源码目录运行：

powershell.exe -NoProfile -File .\windows\uninstall.ps1

申请资料、查询记录和验证码不上传给开发者；本机 163 凭据由 Windows 加密保存，邮件正文和验证码不保存。
