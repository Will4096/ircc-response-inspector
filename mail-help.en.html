Email connection help

Email assistance is optional. Manual code entry remains available. Candidate codes require your confirmation before submission.

163: install, then connect

  1. The helper supports Windows only. Run the installer once; an extension cannot run it automatically.
  2. Download the matching development branch source, extract it and open the folder containing windows.
  3. Open PowerShell there. Replace YOUR_EXTENSION_ID below with the ID shown under Installation help in settings.
powershell.exe -NoProfile -File .\windows\install.ps1 -ExtensionId YOUR_EXTENSION_ID -InstallPython

Per-user installation, no administrator rights required. If Python is missing, the installer uses winget. Do not change system execution policies to bypass restrictions.

  1. Return to settings and check the local helper.
  2. Enable IMAP in 163 webmail settings and generate an app password.
  3. Enter the receiving address and app password, then verify and enable. This is not your webmail login password. Leave it empty only when a connection for the same address is already saved.

Helper available does not mean the mailbox is connected. Wait for Connected after verification.

Gmail: developer preview

A Google Cloud OAuth Web client with Gmail API enabled is required. Add the Redirect URI shown in settings, enter the Client ID and authorize the matching Gmail account.

The read-only scope permits mailbox-wide reading, not only IRCC messages. The extension filters matching messages while waiting for a code. Tokens remain in memory; reconnect after restart or expiry.

Troubleshooting and removal

  • Helper unavailable: install for the current extension ID, then check again. A changed extension ID needs a new binding.
  • Verification failed: check IMAP and the app password, not your webmail login password.
  • Disable assistance to continue with manual codes.

Remove the local connection in settings and revoke access with your email provider when no longer needed. To uninstall the helper, run from the source folder:

powershell.exe -NoProfile -File .\windows\uninstall.ps1

163 credentials are encrypted by Windows. Email bodies and verification codes are not saved. Application data is not uploaded to the developer.
