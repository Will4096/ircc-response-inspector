Install, then connect

Installation help is now available beside Check local helper, without leaving settings.

  1. Download the bundled helper installer.
  2. Copy the command and run it in Windows PowerShell. Select the downloaded script when prompted.
  3. Wait for Installation complete, then check the helper in settings.
The command checks the selected script hash before installation. Initial setup may download Python through winget and accept its installation agreements. Enable IMAP in 163 and use a client app password; no email password is requested by the installer.
