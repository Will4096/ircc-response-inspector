Install, then connect

Installation help is now available beside Check local helper, without leaving settings.

  1. Copy the command below. Your extension ID is included.
  2. Open PowerShell from the Windows Start menu, paste and press Enter.
  3. Wait for Installation complete, then check the helper in settings.
The command downloads and verifies a fixed installer, installs dependencies and binds the current extension. No source download or administrator rights are needed. Then enable IMAP and generate an app password in 163 before connecting in settings. The installer never asks for your email password.
