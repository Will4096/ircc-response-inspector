# Documentation illustrations

Only privacy-reviewed derivative illustrations are stored here. Original screenshots, private publishing copy, image prompts, archives and source personal data are excluded.

The four images illustrate version 4.3.1 and were checked visually before publication. Personal names, identifiers, UCI, birth details, mailbox addresses, exact times and secrets are replaced or hidden. Each PNG was flattened and re-encoded without source metadata. Images contain generative editing and layout changes and are not original query evidence.

These documentation images are excluded from the extension runtime ZIP. Full promotional materials remain in the private media repository.
