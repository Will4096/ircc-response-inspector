# 本地 Tracker 模拟与回归测试

运行 `node scripts/mock-tracker.mjs`，打开 http://127.0.0.1:8788 。结束时按 Ctrl+C。

运行 `node scripts/test-mock-tracker.mjs` 自动启动临时端口的模拟站及独立的无界面 Chrome，完成后关闭。默认使用 Windows 标准安装位置的 Chrome，可用 CHROME_PATH 指定其他位置。

- 模拟登录、资料表单、验证码错误与重试、两名申请人、进度、History 分页及会话过期。
- 全部资料为虚构；测试码固定为 123456，不连接真实邮箱。不填写真实资料。
- 页面扫描直接使用项目 scanner.js；查询界面使用真正的 HTML/CSS/JS 配合虚构 Chrome 接口，检查中英文和初始窄窗口下的宽度回归。
- 浏览器使用 dist/ 下的独立临时资料目录，不操作已有浏览器窗口、账号或扩展存储；外部域名解析被禁用。服务器仅监听本机，不代理 IRCC。
- 报告和检查截图输出到被 Git 忽略的 dist/。模拟网站和测试文件不进入扩展运行包，不增加正式扩展权限。

范围：这是本地页面扫描、交互和界面回归环境，不是实际扩展安装测试。正式扩展仍限制在 IRCC 域名；不为测试放宽该限制。浏览器扩展宿主弹窗的最终尺寸、真实页面兼容性、验证码请求绑定、网络捕获及真实邮箱授权仍需少量有针对性的集成验收。现有 tests.mjs 和 mail-tests.mjs 用模拟接口覆盖后台调度及邮箱状态逻辑；本地模拟站不代表通过真实 IRCC/邮箱验收。

之后界面与流程改动优先在此环境及离线测试中验证；仅在需要确认真实网站兼容性时访问 IRCC。
