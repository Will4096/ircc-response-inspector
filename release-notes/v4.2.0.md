# IRCC Response Inspector 4.2.0

## 中文
- 查询、管理申请和设置统一在侧边栏工作区，复用 Tracker 标签页并处理登录失效。
- 可选 Gmail / Windows 163 邮箱辅助，支持续接本次验证码请求；手动输入始终可用。
- 自动验证独立开启：5 秒倒计时、立即验证、暂停与恢复；失败码不自动重试。
- 顶部与每位申请人显示最新 History 日期，保留原始 History 和 Security 状态。
- 支持密码加密备份与导入，中英双语。

下载命名的 ZIP，解压后通过 Chrome 开发者模式加载。已有用户请在原目录更新并重新加载扩展。163 需按设置说明安装 Windows 本机程序（1.5 / 协议 1）；Gmail 需配置自己的 OAuth 客户端。邮箱辅助默认关闭。未通过 Chrome 应用商店审核；自动化验证使用模拟数据，真实服务可能变化。

## English
- One persistent side-panel workspace, Tracker tab reuse and expired-session handling.
- Optional Gmail / Windows 163 assistance with request continuation and manual fallback.
- Separate opt-in automatic verification: cancellable five-second countdown, verify now, pause and resume. Failed codes are not retried automatically.
- Latest History date shown overall and per applicant; raw History and Security preserved.
- Password-encrypted backup/import and Chinese/English support.

Download the named ZIP and load its extracted folder in Chrome Developer mode. Update existing installations in their original folder and reload. Windows 163 requires helper 1.5 / protocol 1; Gmail requires your own OAuth client configuration. Mail assistance is off by default. This is not a Chrome Web Store approval. Automated checks use synthetic data; live services can change.
