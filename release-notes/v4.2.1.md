# IRCC Response Inspector 4.2.1

## 中文
- 修复切换 profile 后 Tracker 仍停留在上一份申请的问题。
- 切换时停止旧查询及取码，优先使用官网可见的退出操作；否则在原标签页重新打开查询入口。
- 重新登录或提交当前申请前，阻止从旧申请页面继续查询或提交验证码。
- 保留分 profile 的记录，并支持关闭邮箱辅助后的手动提交。

## English
- Fix stale Tracker application sessions after switching profiles.
- Stop previous capture and mail requests. Use the visible official sign-out action when available, otherwise restart the query entry in the same tab.
- Block old results and verification submissions until the selected application starts a fresh flow.
- Preserve isolated records and support manual submission with mailbox assistance disabled.
