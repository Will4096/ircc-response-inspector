## 中文

首个 GitHub Release。非 IRCC 官方工具，与加拿大政府无隶属关系。

- 多 profile 资料管理与官方 Tracker 表单填写。
- 手动输入邮箱验证码，验证后查询申请进度；不读取邮箱。
- 分申请人显示进度、完整 History 和 Security 原始状态代码。
- 与上次成功查询对比，标记状态变化及新增历史记录。
- 默认中文，支持 English；中文保留原网站英文字段名。
- 数据保存在本机；新增双语隐私政策、本地数据清除及已知认证字段遮盖。

### 安装

下载下方 **ircc-response-inspector-v3.4.0.zip**，解压后打开 `chrome://extensions` → 开启开发者模式 → 加载已解压的扩展程序，选择含 `manifest.json` 的文件夹。

升级时使用“重新加载”并刷新 Tracker。申请信息、导出文件仍可能包含个人敏感信息，请勿公开分享真实数据。官方页面可能变化，本工具不预测审批结果，不猜译未公开状态代码。GitHub Release 不代表已通过 Chrome 应用商店审核。

## English

First GitHub release. An unofficial tool, not affiliated with IRCC or the Government of Canada.

- Multiple application profiles and official Tracker form autofill.
- Manual email verification code entry; no mailbox access.
- Per-applicant progress, complete History and raw Security status codes.
- Compare successful checks and highlight changes and new History entries.
- Chinese by default, with English support and original Tracker field names retained.
- Local data storage, bilingual privacy policy, deletion controls and redaction of known authentication fields.

### Install

Download **ircc-response-inspector-v3.4.0.zip** below and extract it. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the folder containing `manifest.json`.

When upgrading, reload the extension and refresh Tracker. Results and exports can still contain sensitive personal information. The official site may change. This extension does not predict decisions or interpret undocumented codes. A GitHub release is not Chrome Web Store approval.
