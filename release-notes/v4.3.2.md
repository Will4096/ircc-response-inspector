# IRCC Response Inspector 4.3.2

## 中文
- 查询页明示申请状态、补件、期限和决定以 IRCC 官方账户信息及正式通知为准。
- 设置 → 关于新增可展开的使用说明与免责声明，说明非官方身份、展示限制、Security 与 History 时间的边界以及用户操作与隐私。
- 查询页链接在原工作区展开说明，保留未保存输入，不增加强制同意或弹窗。

## English
- Add a visible query-page notice that official IRCC account information and formal notices take precedence.
- Add an expandable usage notice in Settings → About covering unofficial status, display limitations, Security/History scope, user actions and privacy.
- Open the notice in the existing workspace without losing drafts or adding a mandatory consent dialog.
