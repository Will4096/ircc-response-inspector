# IRCC Response Inspector 4.3.1

## 中文
- 在申请人进度卡片标题栏新增原始数据导出菜单，可选择明文 JSON 或密码加密文件。
- 确认窗口展示目标申请和响应数量；加密时才显示密码输入，支持键盘取消。
- 与设置页共用导出服务。取消、切换申请或查询批次变化时阻止旧上下文下载，并清空密码。
- 保留设置中的 profile 强制加密导入/导出和原始数据解密功能。

## English
- Add raw-data export to the applicant-progress card header, with plain JSON and password-encrypted file choices.
- Confirm the target application and response count; show password fields only for encryption and support keyboard cancellation.
- Share the export service with Settings. Cancel, profile changes and new query contexts prevent stale downloads and clear passwords.
- Keep encrypted profile transfer and raw-file decryption in Settings.
