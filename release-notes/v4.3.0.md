# IRCC Response Inspector 4.3.0

## 中文
- 将数据传输拆为申请资料和最新原始查询响应两个独立区域。
- Profile 导入/导出必须密码加密；只包含资料，导入前预览并按 ID 合并，保留其他申请及设置。兼容读取旧版加密备份中的资料。
- 原始响应按申请导出，可选择明文 JSON 或密码加密。保留最新查询的完成/进行中状态，不用旧结果替代新的空查询。
- 支持在本机解密原始数据为 JSON，不回写插件。已知认证字段遮盖，Security 原始值保留；明文结果仍需自行脱敏后分享。

## English
- Separate profile transfer and latest raw query response export.
- Profile files require password encryption and contain profiles only. Preview and merge by ID, preserving other profiles and settings. Older encrypted backups supply profiles only.
- Export raw responses for one profile as plain JSON or optionally encrypted files. Include current query status and never substitute an older success for a newer empty query.
- Decrypt raw files locally to JSON without import. Known authentication fields are redacted and Security values preserved; redact personal information before sharing plain exports.
