# IRCC Response Inspector v4.3.3

## 中文

- 修复业务响应在采集、保存、导出、加密及解密中被递归脱敏的问题。明文和密码加密均保留原始响应；新采集记录包含原始响应文本。
- 增加独立采集完整性信息：说明查询进行中、响应超限、保留数量截断、请求或读取失败及旧记录完整性未知。查询完成不代表取得官网全部数据。
- 默认加密，仍支持明确选择明文 JSON；导出超过大小限制时停止下载，不截断文件。
- 发布内容检查与业务数据处理分离；安装包排除私人数据、开发文件和环境路径，导出文件加入 Git 忽略规则。
- 更新后重新加载扩展。旧记录中已经被替换的内容无法还原，需重新查询。Windows 本机程序仍为 1.6，本次修复不要求升级程序。

- 修复展示版本残留导致 Chrome 仍显示旧版本的问题；构建时拒绝不一致的版本号。
- 验证范围为合成数据回归和隔离浏览器测试，不代表真实账号、邮箱提供商或平台审核通过。Gmail 仍需自行完成开发配置；其他使用边界见隐私政策及 v4.3.2 发布说明。

## English

- Remove recursive redaction from business-response capture, storage, raw export, encryption and decryption. Plain and encrypted exports preserve captured content; new captures include original response text.
- Add separate integrity metadata for ongoing queries, capture limits, evictions, request/read failures and unknown legacy completeness. Query completion does not imply capture of all official data.
- Default to encryption while retaining an explicit plain JSON option. Oversized exports stop without truncation.
- Separate publication hygiene from runtime user data. Exclude private data, development assets and environment paths from runtime packages; ignore local export files in Git.
- Reload the extension after updating. Previously redacted records cannot be reconstructed; run a new query. Windows helper 1.6 remains unchanged.

- Fix a stale display version that made Chrome show the previous version; builds reject mismatched version fields.
- Validation uses synthetic regression and isolated browser tests, not live-account/provider validation or platform approval. Gmail remains developer-configured; other limitations are recorded in the privacy policy and v4.3.2 notes.
